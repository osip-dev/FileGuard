# FileGuard 🛡️

**FileGuard** — это учебная утилита на Python для проверки целостности файлов с помощью криптографических хеш-функций (SHA-256). Проект создан для изучения основ программирования и кибербезопасности.

## 🚀 Что делает этот проект?
На первом этапе скрипт умеет безопасно читать файлы «кусками» (чанками) любой величины и вычислять их уникальный цифровой отпечаток (хеш). Если содержимое файла изменится хотя бы на один символ, хеш полностью изменится.

## 💻 Как запустить?

1. Убедись, что у тебя установлен **Python**.
2. Скачай репозиторий или файл `fileguard.py`.
3. Запусти скрипт в терминале:

```bash
python fileguard.py
